PORTFOLIO WEBSITE
=================

วิธีใช้งาน
1. แตกไฟล์ ZIP นี้
2. นำรูปภาพจริงของนักเรียนและกิจกรรมใส่ไว้ในโฟลเดอร์ images
3. ตั้งชื่อไฟล์รูปให้ตรงตามนี้ (ตัวพิมพ์เล็กทั้งหมด):
   - kranokwan.jpg   รูปกนกวรรณ (แนวตั้ง)
   - pattanawit.jpg  รูปพัฒนวิช (แนวตั้ง)
   - volunteer.jpg   รูปกิจกรรมจิตอาสา (แนวนอน)
   - sports.jpg      รูปกิจกรรมกีฬาสี (แนวนอน)
   - asean.jpg       รูปกิจกรรมวันอาเซียน (แนวนอน)
4. เปิด index.html ด้วย Chrome

หมายเหตุ
- รูปนักเรียนใช้ object-fit: cover และกรอบแนวตั้ง
- รูปกิจกรรมใช้ object-fit: cover และกรอบแนวนอน
- เว็บไซต์รองรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- ชื่อไฟล์รูปต้องตรงกับที่กำหนด หากรูปเป็น PNG ให้เปลี่ยนทั้งนามสกุลใน HTML ให้ตรงด้วย
- ประวัติการศึกษาและเกรดเฉลี่ยที่ได้รับมาเป็นข้อมูลชุดเดียว (กนกวรรณ) จึงควรตรวจสอบก่อนนำไปอ้างว่าเป็นข้อมูลของทั้งสองคน
